##  Sobre o projeto

Calculadora de média ponderada desenvolvida em Java.
O programa recebe o nome e as notas dos alunos, calcula a média
 e ao final, apresenta a quantidade de alunos cadastrados e a média
geral da turma.

##  Funcionamento

-  Cadastro de alunos
-  Média ponderada dos dois bimestres
-  Cadastro contínuo até `-1`
-  Contagem de alunos
-  Cálculo da média geral da turma

##  Conceitos utilizados

- `Scanner`
- `while`
- `if`
- Variáveis e operadores
- Média ponderada
- Formatação com `printf`
